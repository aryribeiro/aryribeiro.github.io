# Amazon Connect project

Personal page of Ary Ribeiro, AWS Solutions Architect: <https://aryribeiro.github.io>

The page is available in English, Portuguese and Spanish. Its chat and phone line are a live Amazon Connect contact center with an AI assistant (Jarvis), built with AWS CloudFormation.

This repository holds only the static page: HTML, CSS and JavaScript, with no build step. The contact center itself runs on AWS.
